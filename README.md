## 📖 Project Overview

The `Comparison_of_movie_rating_across_all_sites.ipynb` notebook includes:

- **Loading and cleaning** movie ratings data from multiple sites
- Extracting movie release years and analyzing trends over time
- Comparing ratings across platforms (e.g., Rotten Tomatoes, Metacritic, IMDb)
- Identifying which platforms are stricter or more lenient in their scoring
- Creating **visualizations** (boxplots, scatter plots, heatmaps) to present findings

This project showcases how to perform **exploratory data analysis (EDA)** and draw actionable insights from **real-world datasets.**

---

## 🗂️ Dataset

- **Source:** Movie ratings dataset from multiple review sites (Fandango, Rotten Tomatoes, Metacritic, IMDb, etc.)
- **File Used:** `all_sites_scores.csv`
- **Key Columns:**
  - Movie title
  - Ratings from different review platforms
  - Year of release

---

## 🛠️ Features Covered

✅ Data cleaning and preprocessing (handling missing data, extracting release years)  
✅ Use of `Pandas` and `NumPy` for data manipulation  
✅ Data visualization with `Matplotlib` and `Seaborn`  
✅ Side-by-side rating comparison across platforms  
✅ Analytical questions like:  
   - Which site gives the highest/lowest average ratings?  
   - Do certain years have better-rated movies?  
   - Are critics' scores aligned across different sites?

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/movie-ratings-comparison.git
   cd movie-ratings-comparison
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch the notebook:
   ```bash
   jupyter notebook Comparison_of_movie_rating_across_all_sites.ipynb
   ```

4. Explore the insights and enjoy the visualizations! 📊
